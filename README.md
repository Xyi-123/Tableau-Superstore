# Tableau Superstore
This is a Tableau dashboard project created as part of a data visualization assignment. The dataset used is Tableau's public "Superstore" dataset, and the project focuses on customer behavior analysis through visual analytics.

## Dashboard Overview

The dashboard includes multiple interactive visualizations to answer key business questions:

1. **Top-Spending Customers**  
   - A bar chart showing which customers spent the most, based on combined purchases across product types.

2. **Spending by Education Level**  
   - A stacked bar chart comparing how different education groups spend on categories such as wine, meat, and gold products.

3. **Online Purchases by Marital Status**  
   - A box plot analyzing whether single or married customers buy more online.

4. **Complaints vs. Total Spend**  
   - A scatter plot to examine if higher-spending customers are more likely to file complaints.

5. **Sales Channel Preference by Income Group**  
   - A visualization comparing customer interaction across catalog, web, and store channels, segmented by income brackets.
